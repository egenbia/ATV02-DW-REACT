# ATV02-DW-REACT — Consumo de API no React

## 📖 Sobre o projeto

Aplicação web desenvolvida em **React** com **Next.js** que consome a [Rick and Morty API](https://rickandmortyapi.com/), uma API pública.

A aplicação permite:

- **Listar** todos os personagens da série Rick and Morty, exibindo nome, imagem, status, espécie, origem e localização.
- **Visualizar o detalhe** de um personagem específico ao clicar em "Ver detalhes", com informações completas como gênero, número de episódios em que aparece e muito mais.

---

## 🛠️ Tecnologias utilizadas

- [React](https://react.dev/)
- [Next.js](https://nextjs.org/)
- [Axios](https://axios-http.com/) — requisições HTTP
- CSS Modules + CSS Global
- Hooks: `useState`, `useEffect`

---

## 🚀 Como rodar o projeto

**1. Clone o repositório e acesse a pasta do projeto:**

```bash
git clone https://github.com/egenbia/ATV02-DW-REACT.git
cd ATV02-DW-REACT/rick-morty-api/front-end-react
```

**2. Instale as dependências:**

```bash
npm install
```

**3. Inicie o servidor de desenvolvimento:**

```bash
npm run dev
```

**4. Acesse no navegador:**

```
http://localhost:3000
```
